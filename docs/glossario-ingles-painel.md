# Glossario ingles do painel do operador

Termos fixos para os textos ingleses (`frontend/src/i18n/en.json`) do painel do operador. Usar sempre
estes, em singular e plural, em todos os ecras; nao alternar com sinonimos. O portugues nao muda.

| Portugues | Ingles | Uso |
|---|---|---|
| Reserva / Reservas | Booking / Bookings | Qualquer reserva de um cliente (menu "Bookings", "New booking"); nunca "Reservation". |
| Unidade / Unidades | Unit / Units | Tour, quarto, viatura ou mesa que o operador vende; o menu mostra o nome do tipo (Tours & Activities, Rooms, Fleet, Tables). |
| Hospede / Pessoa | Guest / Guests | Quem participa ou fica alojado numa reserva (contagens de pessoas, chegadas). |
| Cliente / Clientes | Customer / Customers | A ficha de quem reserva no CRM (menu "Customers"); nao usar "Client". |
| Operador | Operator | A empresa que usa o SalDesk (outros operadores, parcerias entre operadores). |
| Voucher | Voucher | Codigo de desconto ou oferta emitido pelo operador; nao usar "Coupon". |
| Afiliado / Afiliados | Affiliate / Affiliates | Quem vende reservas em troca de comissao (programa de afiliados). |
| Colaboradores / Equipa | Staff | Pessoas que trabalham para o operador (menu "Staff", "staff member"); nao usar "Employees". |
| Dashboard | Dashboard | O ecra inicial do painel. |
| Definicoes | Settings | O ecra de configuracao da conta e do negocio (menu "Settings"). |
| Automacoes | Automations | Mensagens e tarefas automaticas (menu "Automations"). |
| Integracoes | Integrations | Ligacoes a plataformas externas; o item do menu chama-se "Channel Manager". |
| Frota | Fleet | As viaturas de um rent-a-car ou de um operador de actividades. |
| Plano | Plan | Subscricao do SalDesk (Starter, Pro, Business): "Pro plan", "Pro feature", "View subscription plans". |
| RH | HR | Recursos humanos: o ecra "HR" com ferias, documentos e certificacoes da equipa. |
| Ferias / Licenca | Leave | Ausencias do colaborador ("Leave", "Leave request", "My leave"); o tipo "ferias" e "Annual leave", os outros "Sick leave", "Maternity leave"... |
| Direito a ferias | Leave entitlement | Dias de ferias a que o colaborador tem direito por ano ("Entitlement", "Set entitlement"). |
| Salario / Salarios | Salary / Salaries | O vencimento de um colaborador; a area de processamento em Financeiro e "Payroll" se aparecer. |
| Horario / Turno | Schedule / Shift | "Usual schedule" para os dias habituais de um colaborador; "Shift" para um turno com hora. |
| Documento | Document | Contratos e documentos de identificacao guardados na ficha do colaborador. |
| Certificacao | Certification | Formacao ou certificado de um colaborador ou guia ("Training and certifications"). |
| Checklist | Checklist | Lista de verificacao diaria do pessoal ("Today's checklist"). |
| Tarefa | Task | Tarefa do quadro do pessoal ("New task", "Tasks"). |
| Trabalho (atribuicao) | Job | Servico atribuido a um colaborador ou guia ("Next job", "12 jobs"); nao usar "Work". |
| Cargo / Funcao | Role | O cargo de um colaborador ("Role", "Maintenance", "Receptionist"). |
| Guia | Guide | Guia de actividades (menu "Guides"). |
| Vendedor de Praia | Beach Seller | O cargo e o modo de venda na praia ("Beach Sellers"). |
| Disponibilidade / Folga | Availability / Day off | Dias em que o colaborador pode trabalhar; "Day off" para folga. |
| Manutencao / Intervencao | Maintenance | Ecra "Maintenance" e cada registo feito numa viatura ("Record maintenance", "Maintenance history"); nao usar "Repair job". |
| Revisao (viatura) | Service | A revisao periodica de uma viatura ("Next service (km)"); o tipo gravado continua "Revisao". |
| Seguro / Inspecao / IUC | Insurance / Inspection / IUC | Documentos da viatura com validade; IUC e nome oficial e nao se traduz. |
| Ocorrencia / Ocorrencias | Incident / Incidents | Registo de algo que correu mal na operacao (menu "Incidents", "Log incident"); nao usar "Occurrence". |
| Severidade | Severity | Gravidade de uma ocorrencia: Low, Medium, High, Critical. |
| Frota e Equipamento | Fleet and equipment | Ecra da frota: viaturas (Vehicle), equipamento (Equipment) e material (Gear). |
| Meteorologia | Weather | Ecra da previsao do tempo ("7-day forecast", "Bad weather forecast for..."). |
| Limpeza de quartos | Housekeeping | Ecra "Housekeeping": estados Clean, Dirty, Being cleaned, Inspection, Blocked. |
| Financeiro | Financial | Ecra das financas (menu "Financial"); areas Revenue, Expenses, Payroll, Commissions, Obligations, Profit and loss. |
| Receita / Receitas | Revenue | Dinheiro que entra ("Total revenue", "Gross revenue", "Manual revenue"); nao usar "Income" nem "Sales". |
| Despesa / Despesas | Expense / Expenses | Custo registado pelo operador ("Record expense", "Operating expenses"); a categoria gravada continua em portugues. |
| Folha salarial / Salarios (area) | Payroll | A area de salarios do Financeiro e o total pago ao pessoal ("Total payroll/month"). |
| Comissao / Comissoes | Commission / Commissions | O que se paga aos vendedores de praia e parceiros ("Pay commission"). |
| Caixa | Cash | O separador dos pagamentos em dinheiro ("Cash payments"); "Cash flow" so se aparecer o fluxo de caixa. |
| Previsao | Forecast | Previsao de receita ("Weekly forecast") e o ecra "Demand forecast" (Previsao de Procura). |
| Fim de Turno | End of shift | O resumo do dia do vendedor de praia ("End of shift"); o texto partilhado e "Shift summary". |
| Meta Pessoal | Personal goal | O cartao de recordes do vendedor de praia ("Record sales/day"). |
| Resultado | Profit and loss / Net result | A area "Profit and loss"; o valor final e "Net result". |
| Margem | Margin | "Net margin", "Margin" por tour. |
| Obrigacoes | Obligations | INPS, IUR, seguros e subscricao; INPS, IUR, NIF, DNRE, Vinti4 e SISP sao nomes oficiais e nao se traduzem. |
| Analises | Analytics | O ecra "Analytics" (Score de saude = "Business health score", funil = "Conversion funnel"). |
| Sazonalidade / Epoca alta | Seasonality / High season | Analise da previsao de procura ("High seasons", "Low seasons"). |
| Levantamento / Devolucao (viatura) | Pick-up / Drop-off | Entrega e recolha de uma viatura de aluguer ou o ponto de encontro de um tour ("Car pick-up", "Car drop-off"); nao usar "Return" nem "Collection". |
| No-show | No-show | Cliente que nao apareceu ("Record No-show"); o estado gravado e "no_show". |
| Manifesto | Manifest | A lista de participantes de um tour num dia, que tambem se imprime ("Participant Manifest"). |
| Caucao | Deposit | Valor retido ao cliente do rent-a-car; as opcoes sao Returned, Partly retained e Fully retained. |
| Lista de espera | Waiting list | Reserva de restaurante sem mesa disponivel. |
| Turno (restaurante) | Shift | Almoco (Lunch) ou jantar (Dinner) de uma reserva de restaurante. |
| Pax | Guests | Numero de pessoas de uma reserva de tour (coluna "Guests"); o gravado nao muda. |
| Vagas | Spots | Lugares livres de uma unidade num dia do calendario ("3/6 spots", "3 spots left"). |
| Bloquear datas | Block dates | Fechar uma unidade a reservas num intervalo do calendario ("Blocked", "Unblock"). |
| Ponto de encontro | Meeting point | Onde o grupo se junta para um tour ("Meeting point location"); o gravado e texto livre mais lat/lng. |
| Dificuldade | Difficulty | Facil / Moderado / Dificil gravados; mostram-se "Easy", "Moderate", "Hard". |
| Comodidades | Amenities | Lista fixa de extras de uma actividade ("Equipment included", "Towels"); o gravado e o texto portugues. |
| Opcao (variante) | Option | Variante de uma actividade com preco proprio ("Per person", "Per group", "Per vehicle"); o tipo gravado e per_person, per_group, per_vehicle. |
| Suplemento de idioma | Language surcharge | Valor fixo por reserva quando o cliente escolhe o idioma do guia. |
| Oferta | Offer | Desconto automatico por periodo ("Automatic offers"). |
| Paragem / Itinerario | Stop / Itinerary | Pontos de um tour com coordenadas opcionais. |
| Escalao de preco | Price tier | Preco privado por intervalo de pessoas ("1-2 guests at 80"). |
| Horario com lugares | Time slot | Hora de um tour com lugares proprios ("Time slots with limited spots"). |
| Viatura | Vehicle | Carro ou moto do rent-a-car ("Register vehicle", "New Vehicle"); a matricula e "Licence plate". |
| Mesa / Zona | Table / Zone | Mesa de restaurante e a zona onde fica; as zonas gravadas (interior, esplanada, terraco, vip, privado) mostram-se "Indoor", "Outdoor seating", "Terrace", "VIP", "Private". |
| Epoca | Season | Preco do quarto por epoca ("Low season", "Mid season", "High season", "Peak"). |
| Motorista | Chauffeur | Condutor incluido na reserva de um Executivo ("Chauffeur rate (per day)"). |
| Avaliacao / Avaliacoes | Review / Reviews | Opiniao e nota de um cliente depois da actividade ou estadia (menu "Reviews", "Review request"); nao usar "Rating" para o texto todo. |
| Historico de envios | Sending history | Registo das mensagens enviadas pelas automacoes ("Sending history"); os modelos de mensagem ao cliente ficam em portugues e ingles. |
| Gestor | Manager | O dono ou responsavel do operador nos chats ("Manager", "Management"); nao usar "Owner". |
| Pedido (restaurante) | Order | Pedido de uma mesa ao restaurante (menu "Orders"); os estados gravados received, preparing, ready, delivered, cancelled mostram-se "Received", "Preparing", "Ready", "Delivered", "Cancelled". |
| Preco acordado | Agreed price | Preco negociado com um cliente na sua ficha ("Agreed price"). |
| Etiqueta (cliente) | Tag | Marca livre de um cliente; as etiquetas gravadas (VIP, grupo, corporativo, fidelizado, novo, recorrente...) mostram-se "VIP", "group", "corporate", "loyal", "new", "returning". |

## Regras

- Ingles britanico (`en-GB`): "programme", "optimise", "centralised"; datas e numeros pelo `en-GB`.
- Nomes de marcas e de planos nao se traduzem: SalDesk, Viator, GetYourGuide, WhatsApp, PayPal, SISP Vinti4,
  Booking.com, Airbnb, Starter, Pro, Business, Channel Manager.
- Valores guardados ou comparados no codigo (estados, categorias, cargos, metodos de pagamento) ficam em
  portugues; so o rotulo mostrado passa pela traducao.
- Alemao e holandes seguem os mesmos conceitos (Buchung / Boeking, Einheit / Eenheid, Kunde / Klant...).
